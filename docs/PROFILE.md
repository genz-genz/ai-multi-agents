## Brainstorm
- เป้าหมาย: พื้นที่ส่วนตัว ชิล ๆ เน้นตัวตน ไม่ใช่ portfolio
- เจ้าของไม่อัปเดตเอง · คนที่แวะมามีส่วนร่วมผ่าน guestbook (ข้อความเท่านั้น)
- Must: ประโยคสุ่มหน้าแรก · การ์ด "เพลงสุ่มวันนี้" · guestbook ใช้ชื่อเล่นอย่างเดียว · Bio ครบทุกย่อหน้า · ธีมขาวมินิมอล อ่านง่ายบนมือถือ
- เพลงสุ่ม: ดึงชาร์ตไทยจาก Apple Music RSS (ฟรี ไม่ใช้ key) · เจ้าของและผู้เข้าชมไม่ต้องทำอะไร · ดึงฝั่ง server + cache · API ล่ม = ซ่อนการ์ด หน้าเว็บไม่พัง · ต้องเช็ก endpoint ก่อน implement
- Nice: ปุ่ม "สุ่มใหม่" · "สถานะวันนี้" สุ่ม % (นั่งเฉย ๆ / ทำตัวเหมือนยุ่ง) · ลิงก์ "ฟังต่อ" ไปหน้าเพลงบน Apple Music (ไม่ฝัง player)
- Later: หน้า 404 ขำ ๆ · ตัวนับคนทักจาก guestbook · โหมดมืด
- About: เลือกจาก "Hello world" / "สามโหมดชีวิต" / "ยังไม่รู้จะไปไหน ขอฟังเพลงก่อน"
- หลีกเลี่ยง: ข้อมูลส่วนตัว · now-playing real-time · API key / ความลับ · embed player · บล็อก/ล็อกอิน/แอดมิน
- Guestbook: ไม่เก็บ/แสดงอีเมล หรือ IP · escape ข้อความ · จำกัดความยาวและความถี่ · ห้ามลิงก์
- ประโยคสุ่ม: ระบบประกอบเองจากแม่แบบประโยคไทยในโค้ด + คำจาก Interests (เช่น "วันนี้ขอ{interest}ไปก่อน") · เจ้าของและผู้เข้าชมไม่ต้องทำอะไร · ไม่พึ่งเน็ต ไม่ใช้ key ไม่ล่ม
